# 📊 Database Portfolio (DAD 220)

## 📌 Overview
This repository contains my database coursework and projects from DAD 220 at Southern New Hampshire University. These projects demonstrate my ability to design databases, write SQL queries, analyze data, and apply relational database concepts.

All SQL queries were executed using the **SNHU Codio virtual lab environment**, where I practiced and tested database commands in a controlled academic setting.
